# About This Site

This is a technical documentation site focused on firmware development, particularly for FreeRTOS-based embedded systems.

## Content Overview

### Firmware Development Standards
Comprehensive coding standards and best practices for developing safety-critical firmware, with particular focus on:
- Medical device compliance (IEC 62304)
- Automotive standards (ISO 26262)
- FreeRTOS implementation patterns
- Static memory allocation strategies

### Interactive Demonstrations
Various 3D and physics-based demonstrations showcasing:
- Cannon.js physics simulations
- Three.js 3D visualizations
- Real-time rendering techniques

## Technical Focus

The documentation emphasizes:
- **Safety-critical development** practices
- **Deterministic memory allocation**
- **Task synchronization** patterns
- **Error handling** strategies
- **Testing and validation** approaches
